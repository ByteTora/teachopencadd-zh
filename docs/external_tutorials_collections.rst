Python 编程
~~~~~~~~~~~~~~~~~~

TeachOpenCADD 平台并非从零开始的 Python 编程课程，而是教授如何以编程方式解决化学信息学和结构生物信息学中的任务。
如果你希望在深入 TeachOpenCADD 材料之前先了解 Python 编程入门，这里有几个很棒的资源：

- 来自 `Volkamer Lab <https://volkamerlab.org/>`_ 和 Charité 医学院 `Ritter Lab <https://psychiatrie-psychotherapie.charite.de/metas/person/person/address_detail/prof_dr_rer_nat_kerstin_ritter/>`_ 的 `AI in Medicine 课程 <https://github.com/volkamerlab/ai_in_medicine>`_：Python 基础、Jupyter Notebook 以及 ``pandas``、``matplotlib``、``scikit-learn`` 等重要数据科学包的入门
- 来自 `GDCh/CIC <https://en.gdch.de/network-structures/gdch-structures/computers-in-chemistry-cic.html>`_ 团队的 `Python for Chemists 课程 <https://github.com/GDChCICTeam/python-for-chemists>`_：面向自然科学家的 Python 速成入门
- 来自 `The Molecular Sciences Software Institute <https://molssi.org/>`_ 的 `MolSSI 教育资源 <http://education.molssi.org/resources.html>`_：Python 编程基础与数据分析的教程集合，也包括软件开发与计算分子科学等更进阶的材料
- 来自 `Software Carpentry <https://software-carpentry.org/>`_ 的 `核心课程 <https://software-carpentry.org/lessons/>`_：Python、Git、命令行界面等入门
- `Python、Git 和 Jupyter 的最佳实践 <https://zenodo.org/record/4630714>`_，一份用于我们 2021 年 CADD 模块课程（柏林自由大学生物信息学硕士课程的一部分）入门环节的讲义。
- 来自 Czodrowski Lab 的 `5 Minutes of Fame <https://github.com/czodrowskilab/5minfame>`_：以 Python 为主题的科学与技术新闻短会
