    本教程目标¶

    NGLView 是一个强大的 Jupyter 小部件，它允许你在笔记本中以3D交互视图显示分子结构！它支持单个构象和轨迹，以及多种多样的表示形式。在本教程中，我们将介绍如何在不同场景中使用它，从简单的案例到更复杂的案例。

    理论¶

    NGL 和 NGLView¶

    NGL 是一个 WebGL 加速的 JavaScript 库，用于在浏览器中展示3D大分子结构。它不需要安装任何软件！它已被数据科学社区广泛采用，部分得益于 NGLView 在 Jupyter 生态系统中的集成。虽然紧密相连，但 NGL 和 NGLView 是两个独立的项目，理解这个区别至关重要。

    • NGL 是使用 WebGL 在浏览器中渲染分子结构的 JavaScript 库。它可以嵌入到任何网页中，参见演示应用。

    • NGLView 封装 了 NGL，使其可以从运行 Python 内核的 Jupyter 笔记本中使用。这得益于 IPyWidgets 项目提供的集成。

    当你 import nglview 时，你正在加载一个知道如何与底层 JavaScript 库通信的 Python 包。告诉 nglview 你想看哪个结构的过程比你想象的要复杂！

    • 导入包：

      • import nglview 仅仅 加载 nglview Python 包。这通常由 conda 或 pip 提供。

      • Python 包现在必须找到 JavaScript 组件。这些组件作为 Python 包数据文件的一部分被捆绑在一起，但它们需要被放置在正确的位置，以便浏览器可以在 Jupyter 界面中加载它们。

      • 成功导入 Python 包并不一定意味着 JavaScript 层已正确加载！注意：这是一个常见错误，我们在教程末尾提供了一些故障排除方法。

    • 显示3D结构：

      • 当你请求显示一个 PDB ID 时，NGLView 会将你想要下载的文件 URL 传递给 NGL（我们将使用一个单独的函数安全下载 PDB 文件，然后将其传递给 NGLView）。然后，JavaScript 层接手并将内容下载到浏览器的内存中，为大分子结构创建 JavaScript 对象，然后在支持 WebGL 的 <canvas> HTML5 元素中渲染它。

      • 如果你想打开本地文件，你可以：

        • 用 Python 打开文件，并将文件的 内容 传递给 NGL。

        • 将文件的磁盘位置传递给 NGLView，NGLView 会将其转换为一个 下载 链接，NGL（作为 JavaScript）可以用它来访问文件。注意：此步骤比较脆弱，可能因不同包版本而失效，因此我们建议先在 Python 中打开文件。后面会提供一个示例！

      • 如果你想查看由 Python 库（RDKit、BioPython、MDAnalysis…）提供的分子对象，NGLView 会尝试识别对象模型并将其转换为适合 NGL 的格式（通常是 PDB 字符串）。这通过一些辅助函数透明地完成。

    鉴于这些交互的复杂性，你必须理解 NGLView 只提供了 NGL 最常用功能的 Python 接口。一些高级功能并未直接暴露，但好消息是你可以随时 向 底层 JavaScript 对象 发送 代码片段。

    我们将通过不同的示例在本教程中涵盖所有这些细节。

    NGL 对象模型与术语¶

    当你请求一个3D查看器时，NGLView（Python 包）会创建一个叫做 NGLWidget 的对象，它将 NGL 的 Stage JavaScript 对象封装在一个 IPyWidget 对象中。NGLWidget 充当 Python 和 JavaScript 之间的桥梁。当你在 view 实例上使用自动补全时，你正在探索 NGLWidget 的 Python 属性和方法。

    一旦你进入 JavaScript 领域，你就在操作 NGL 对象模型了。这个模型基本上由 Stage 组成，Stage 可以承载一个或多个 组件。组件 可以是分子结构或几何形状。组件可以用一个或多个 表示形式 渲染。例如，当你看到一个蛋白质配体复合物（比如说 PDB ID 3PK2），你实际上看到的是：

    • NGL 的 Stage，即交互式画布

    • 一个单独的组件，3PK2 的内存中 JavaScript 对象。请注意，一个 组件 可以存储物理意义上的多个 分子 或 模型！

    • 两种表示形式：骨架用 ribbon（飘带），配体用 ball and stick（球棍）

    • 如果你还想看到水分子，你需要再添加一个仅针对溶剂的表示形式。

    表示形式不仅仅包括结构的外观。NGL 实现还将某些类型的测量视为 表示形式。如果你想看到范德华表面，在 NGL 术语中那也是一种表示形式。测量两个原子之间的距离并以指向线显示，那也是一种表示形式。标签也算作表示形式。

    然而，如果你想添加一个指向蛋白质中任意位置的形状，那是一个 shape，它是 component 的一个子类型！

    感到困惑？记住区别的一种方法：表示形式 依赖于 组件提供的坐标。它们自己没有坐标！形状则可以被放置在任意位置，因此它们不是表示形式，而是独立的组件。

    为了确保你掌握了要点，你还可以查看演示应用中的示例（顶部菜单中的下拉菜单）来更熟悉 NGL 术语。每个示例都会在3D画布上加载一个状态，组件位于层次结构的顶层，它们的表示形式在下面。

    这应该涵盖了理论层面的核心概念，但在你亲自实践之前这些可能不太容易理解，所以… 开始吧！

    体验交互式控件¶

    上方的视图是交互式的！你可以使用鼠标进行以下操作：

    • 平移：右键单击 + 拖动

    • 旋转：左键单击 + 拖动

    • Z 轴旋转：Ctrl + 右键单击 + 拖动

    • 缩放：滚轮

    • 居中视图：左键单击想要居中的原子（或其表示形式）

    你还可以通过以下步骤来表示距离、角度和二面角：

    1. 右键单击一个原子。你将看到一个绿色球体包围它。

    2. 右键单击另一个原子。现在你将看到两个绿色球体。用这种方式，你最多可以将四个原子添加到一个选择中（包括第一个原子）。

    3. 再次右键单击你选择的最后一个原子来结束操作。

      • 如果你选择了两个原子，你将看到两个原子之间的虚线，以及报告的距离（单位 Å）。

      • 如果你选择了三个原子，你将看到一个扇形，显示报告的角度（单位 °）。

      • 如果你选择了四个原子，你将看到一个扇形，显示报告的二面角（单位 °）。

    要删除距离/角度/二面角表示，在相同的原子上重复这个操作序列即可。

    使用 PDB 标识符显示结构¶

    目前，nv.show_pdbid 不可用，所以我们使用 get_pdb_nglviewer 函数来替代此过程。

    使用 pypdb.get_pdb_file 从 RCSB PDB 网站获取 PDB 结构，并使用 nv.show_file 显示：

    [5]:

    def get_structure(pdb_id):
    # 下载 PDB 文件内容。
    pdb_file_content = get_pdb_file(pdb_id)
    # 从内容创建 nglview 结构对象
    structure = nv.TextStructure(pdb_file_content, ext="pdb")
    return structure


def get_pdb_nglviewer(pdb_id, default_representation=True, gui=False):
    structure = get_structure(pdb_id)
    # 设置结构查看器
    nglviewer = nv.show_file(structure, default_representation=default_representation, gui=gui)
    return nglviewer

    使用本地文件显示结构¶

    在其他情况下，你可能需要用管道其他部分生成的本地文件来显示结构。要加载本地文件，你需要使用 nv.show_file("path/to/local/file.pdb")。如果你使用 Jupyter Notebook 作为界面，这将直接开箱即用。

    然而，Jupyter 生态系统正在向 Lab 迁移，在那里某些事情的工作方式略有不同。其中之一就是访问本地文件。这是一个已知问题，所以我们在此提供一个变通方案，直到此问题被修复。技巧是先用 Python 打开文件，然后将文件句柄传递给 NGLView，而不是传递路径。你还需要为该文件句柄指定扩展名（此示例中为 pdb）。需要使用 display(...) 将小部件视图显式导出到输出中，因为我们是在 open() 上下文管理器内部。

    [7]:

    with open(DATA / "1ARM.pdb") as f:
    display(nv.show_file(f, ext="pdb"))

    你也可以保存函数返回的小部件（按照惯例命名为 view）并在全局级别评估它：

    [8]:

    with open(DATA / "1ARM.pdb") as f:
    view = nv.show_file(f, ext="pdb")
view

    这样做的好处是允许你从 Python 接口修改小部件的状态，正如你在后续步骤中会看到的。

    将小部件状态保存为截图以供离线查看¶

    在某些情况下，你可能想要截取小部件当前状态的屏幕截图（例如，保存静态预览）。这是一个 必须 涉及三个独立单元格的步骤。尽管将所有这些单元格合并在一起非常诱人，但如果每个单元格不分别运行，它 将不会 工作：

    • view 将显示小部件输出。你可以使用鼠标将其移动到一个好看的方向上，如果你愿意的话。

    • view.render_image(...) 将当前画布内容从 JavaScript 层导出到 Python 层。这就是”截图”的时刻。

    • view._display_image() 将 Python 层的内容导出到单元格输出。

    自定义表示形式¶

    你可以使用 view.add_* 方法添加更多表示形式。以下是可用的方法。请注意，在 NGL 中，表示形式可以包括除蛋白质或配体描绘方式之外的视觉工具。例如，计算（并显示）距离测量也是一种 表示形式。我们稍后会详细讨论这一点，但你现在也可以查看 NGL 文档的这部分内容。

    访问 JavaScript 层¶

    NGL 是一个功能极其强大的 JavaScript 库。NGLView 将最常用的部分导出到 Python，这使我们能够以非常方便的方式控制某些事情。然而，有时我们需要同时利用两层（JS 和 Python）来实现一些高级的表示形式。为此，我们可以使用 nglview.NGLWidget 中的一些私有方法。即：

    • nglview.NGLWidget._remote_call：在 NGL JS 对象上运行一个方法，带有位置参数 args 和关键字参数 kwargs。你必须先选择目标对象：

      • target="Widget"：NGL Stage 的 IPyWidget 封装器。查看公共方法。

      • target="Stage"：在 Stage 上运行任何方法。方法列表。

      • target="Viewer"：在 Viewer 上运行任何方法。查看公共方法。

      • target="compList"：在 compList（Stage 中已加载组件的列表）上运行任何方法。可能对查询 JS 列表以获取特定组件有用。

      • target="StructureComponent"：在 StructureComponent（每个单独的组件）上运行任何方法。方法列表。

    • nglview.NGLWidget._execute_js_code：这将允许你执行任意的 JavaScript 代码。在该代码中，IPyWidget 的 JS 对应物可以用 this 引用。NGL 的 Stage 实例可通过 this.stage 访问。对于复杂情况，它比 _remote_call 更强大！

    让我们先尝试一些简单的例子。

    [59]:

    view = get_pdb_nglviewer("2G1T")  # 人类 ABL1 激酶
view

    Sending GET request to https://files.rcsb.org/download/2G1T.pdb to fetch 2G1T's pdb file as a string.

    让我们添加一些随机文本。这可以通过 addShape 小部件方法来实现。一些注意事项：

    • Widget.addShape 需要参数：一个形状标识符或名称（任意 str）以及一个子列表的列表，其中每个子列表包含”形状”的种类及其参数。在此处查看该函数。

    • 每种形状类型的参数可以在 NGL 文档中查看；例如 text。使用搜索栏找到对应的 *Buffer。

    • 参数以位置方式传递，不带 关键字，只传递值。

    让我们添加一些红色（编码为 RGB [1, 0, 0]）文本（TeachOpenCADD），位于 XYZ 坐标 [60, 0, -20]。

    [60]:

    view._remote_call(
    "addShape",
    target="Widget",
    args=("redText", [["text", [60, 0, -20], [1, 0, 0], 10, "TeachOpenCADD"]]),
)

    请注意，这可以通过类似的方式使用 _execute_js_code 来实现。区别在于如何传递参数，这些参数需要在 f-string 中进行替换。幸运的是，对于一些简单情况，JS 和 Python 共享类似的语法（例如列表和字符串）。让我们再添加一些文本，但这次它是蓝色的，并且在不同位置：

    [61]:

    view._execute_js_code("""
this.addShape("blueText", [["text", [60, 20, -20], [0, 0, 1], 10, "TeachOpenCADD"]])
""")

    这在某些情况下可能很麻烦，但在其他情况下我们别无选择。例如，如果我们想删除其中一个形状，我们只能通过 _execute_js_code 来实现：

    [62]:

    view._execute_js_code("""
this.stage.removeComponent(this.stage.getComponentsByName("blueText").first)
""")
    调试 JavaScript 代码¶

    你可能想知道，如果自动补全不起作用且文档难以理解，你如何找到正确的 JS 命令。你最好的选择是使用浏览器中的开发者工具！

    技巧是将 NGL Widget（在 _execute_js_code 上下文中由 this 表示）导出到浏览器选项卡上下文中。为此，请执行以下代码片段：

    [63]:

    view._execute_js_code("document.nglview = this;")

    如果你打开开发者工具控制台（Chrome 中为 Ctrl+Shift+J，Firefox 中为 Ctrl+Shift+K），你可以在那里输入 document.nglview 并交互式地检查该对象：

    为方便起见，你还可以在 JavaScript 控制台中再执行一行代码，将其别名设置为更快速输入的名称：

    nv = document.nglview;

    然后检查 nv 即可。使用 Tab 的自动补全应该可以按预期工作！

    技巧和注意事项：

    • 大多数有趣的内容都会在 nv.stage 下，例如 nv.stage.compList。

    • 你在控制台中开发的代码片段可以作为 _execute_js_code 代码片段使用，只要将 document.nglview（或你的别名 nv）替换回 this。

    • 如果你从笔记本中重新加载 NGL Widget（例如通过再次调用 nv.show_pdbid(...)），你需要重新运行 view._execute_js_code("document.nglview = this;")。

    • 控制台允许未以 ; 结尾的行，但在代码片段中请确保每行以 ; 结尾。

    • JavaScript 注释以 // 开头，而不是 #。

// Add representation for those atoms
system.addRepresentation("licorice", {sele: around_complete.toSeleString()});
// Restore selection to original one; otherwise changes won't be reflected
system.setSelection(prevSele)
""")

    要参数化这段 JS 代码，你可以在函数中使用 f-strings！但是，请确保执行以下任一操作：

    • 通过加倍来转义已存在的大括号 { }：

    - system.addRepresentation("licorice", {sele: around_complete.toSeleString()});
+ system.addRepresentation("licorice", {{sele: around_complete.toSeleString()}});

    • 通过隐式字符串拼接，将包含 {} 的子字符串与 f-string 部分分开：

    js = (
f"""
// Get first (and only) loaded component: our protein-ligand system
var system = this.stage.compList[{index}];
// Store current selection, we will need it laer
var prevSele = system.selection.string;
// Set selection to our desired ligand
system.setSelection("{ligand}");
// Select all atoms within 5A from the ligand
var around = system.structure.getAtomSetWithinSelection(system.selection, {radius});
"""
# 这些额外的引号创建了两个不同的字符串：上面的 f-string，下面的普通字符串
"""
// Extend selection so it includes full residues
var around_complete = system.structure.getAtomSetWithinGroup(around);
// Add representation for those atoms
system.addRepresentation("licorice", {sele: around_complete.toSeleString()});
// Restore selection to original one; otherwise changes won't be reflected
system.setSelection(prevSele)
"""
# 最终它们仍然会被拼接在一起，但 _拼接_ 发生在 _格式化_ 完成之后 :)
)

    了解了这一点，你可以像这样定义 show_residues_around：

    [66]:

    def show_residues_around(view, component_index=0, selection="ligand", radius=5.0):
    js = (

    )
    view._execute_js_code(js)

    故障排除技巧¶

    Jupyter 生态系统是庞大且快速变化的。跟上最新的新增功能既棘手又耗费资源，因此遇到 NGLView 安装故障并不少见。以下包可能会影响 NGLView 的功能。如果其中某个包最近发生了版本变更（特别是主要版本，如 Jupyter Lab 2 -> Jupyter Lab 3），那可能是你看到错误的原因之一：

    • jupyter

    • jupyterlab

    • notebook

    • ipywidgets

    • nglview 本身

    提示：如果 nglview 可以导入，但你看不到 nv.demo() 的画布，请检查开发者工具控制台（Chrome 中为 Ctrl+Shift+J，Firefox 中为 Ctrl+Shift+K）中的错误信息！尝试加载 JS NGL 库的 404 错误是最常见的错误之一。请按以下步骤进行故障排除！

    如何正确安装 nglview¶

    如果你不了解上述微妙差异，你的计算机上可能会安装了多个 nglview 实例。同时拥有 conda 和 pip 会使情况更加困难，特别是如果你将系统安装与环境安装混用。我们的建议是为你工作的每个项目创建一个全新的环境，并显式指定其依赖项。

    要获得干净的初始状态，你可能需要删除一些会干扰环境特定设置的文件。

    Jupyter Notebook¶
    conda install -c conda-forge nglview
nglview install
nglview enable

    如果这不起作用，有可能是 Jupyter Notebook 找到了其他干扰预期 JavaScript 库的 nglview 安装。Jupyter 将检查的路径用 jupyter --paths 列出。

    为确保加载正确的库（活跃环境中的那些），你可能需要删除一些目录：

    对于 Linux 和 Mac OS：

    # 用户级小部件
rm -rf ~/.local/share/jupyter/nbextensions/nglview-js-widgets/
# 全局 conda 小部件
rm -rf $(conda info --base)/share/jupyter/nbextensions/nglview-js-widgets/

    对于 Windows：

    del %APPDATA%\jupyter\nbextensions\nglview-js-widgets
del %_CONDA_ROOT%\share\jupyter\nbextensions\nglview-js-widgets

    然后，关闭 Jupyter Notebook 标签页和命令行进程，并重新启动。如果这仍然不起作用：

    • 确保 jupyter --paths 显示的位置在 <prefix>/share/jupyter/nbextensions/nglview-js-widgets/ 下不包含 NGL 文件。

    • 运行 conda remove nglview 和/或 pip uninstall nglview，然后重新开始。

    • 使用 Ctrl+Shift+R 强制重新加载浏览器标签页。

    • 查看这个优秀的常见问题文档以获取更多思路。

    Jupyter Lab（v2 风格）¶

    由于 Jupyter Lab 使用不同的扩展系统，它不会受到上述路径优先顺序问题的影响。但是，你需要确保扩展已经安装 并 构建：

    conda install -c conda-forge nglview
jupyter labextension install @jupyter-widgets/jupyterlab-manager nglview-js-widgets
    Jupyter Lab（v3+ 风格）¶

    Jupyter Lab v3 及以上版本使用了一种巧妙的技巧来预编译 JavaScript 库，因此你 只需 使用你喜欢的包管理器安装 nglview 即可。

    conda install -c conda-forge nglview
